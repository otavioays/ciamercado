# Mercado Cia do Lar

Site institucional responsivo do Mercado Cia do Lar, na Vila A, em Foz do Iguaçu.

O projeto aplica o design system editorial fornecido: fundo de papel quente, tipografia de alto contraste, composições geométricas, marcações técnicas e acentos coral, mostarda e oliva.

## Estrutura

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: carrega os módulos visuais `site-01.css` a `site-11.css`.
- `script.js`: menu móvel, status de funcionamento, animações e cópia do endereço.
- `.nojekyll`: evita processamento do Jekyll no GitHub Pages.

## Executar localmente

Abra `index.html` diretamente no navegador ou execute um servidor estático na raiz do projeto. Não há etapa de build.

## Publicar no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.

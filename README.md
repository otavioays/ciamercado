# Mercado Cia do Lar

Site institucional responsivo do Mercado Cia do Lar, na Vila A, em Foz do Iguaçu.

O projeto usa uma direção visual editorial inspirada no design system fornecido: papel quente, tipografia de alto contraste, marcações técnicas, ilustrações vetoriais e acentos coral, mostarda e oliva.

## Estrutura

- `index.html`: site completo, com CSS, ilustrações SVG e JavaScript incorporados.
- `.nojekyll`: impede processamento desnecessário do GitHub Pages.

## Publicação

O site é estático e não exige build. Para publicar pelo GitHub Pages, use a branch `main` e a pasta raiz do repositório.
